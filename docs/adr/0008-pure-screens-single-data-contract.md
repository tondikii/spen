# ADR-0008: Screen murni dengan satu kontrak data, tanpa dunia mock

Kita menghapus seluruh "dunia mock" (`src/data/mock-data.ts`, state module, dan fungsi `*Mock*` di services) yang sebelumnya hidup di production path: screen punya default props yang memanggil data mock, dan sebagian mutasi bahkan bercabang `if (callback) … else mock`. Keputusannya: **setiap screen adalah module murni** — semua view model dan callback adalah props wajib tanpa fallback; data hanya mengalir dari route adapter (`.native.tsx`) yang memanggil services; test komponen membangun fixture inline dan menyuntikkannya melalui seam props yang sama dengan route. Helper presentasi yang pure dipindah ke `lib/presentation`, dan tipe view model dinamai tanpa awalan `Mock` (`BudgetSnapshot`, `PlanItemState`) karena kini hanya jalur database yang ada.

Alternatif yang dipertimbangkan: mempertahankan mock sebagai "fixtures bersama" (berisiko menjadi dunia mock kedua), atau menjadikannya demo mode (ditolak — setup wizard sudah meng-seed data asli, tidak ada kebutuhan produk). Kita juga memilih fixture inline per test daripada builder bersama agar setiap test jelas kebutuhannya.

Konsekuensi: screen tidak bisa dirender "sendiri" tanpa data — itu disengaja; kontrak yang jujur lebih penting daripada kemudahan render mandiri. Route menjadi satu-satunya tempat penyambungan data, sehingga route-level test menjadi mungkin (ditindaklanjuti bersama read model, lihat arah Kandidat 2). Component tests yang lama mengunci angka dunia mock ditulis ulang dengan fixture; peringatan "melebihi alokasi" untuk kategori yang dipilih bebas kini menunggu pasokan limit per kategori dari read model (prop `allocationLimit` sengaja opsional).
