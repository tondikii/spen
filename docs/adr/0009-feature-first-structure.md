# ADR-0009: Struktur folder feature-first dengan src/app sebagai route tipis

Kita mengadopsi struktur feature-first dari `structure-recommendation.md` (konsultasi eksternal, disesuaikan dengan kondisi repo) sebagai target arsitektur: `src/app/` hanya berisi route, parameter navigasi, dan layout — implementasi layar hidup di `src/features/<fitur>/screens/`; query dan operasi database milik fitur pindah ke `src/features/<fitur>/data/`; database inti (client, schema per tabel, provider) pindah dari `db/` ke `src/db/` dengan output migrasi tetap `db/migrations`; folder `src/services/` **dibubarkan total** — service per fitur menjadi repository di `data/`, `ai-service` menjadi integrasi di `lib/`, `backup` dan `settings` mengikuti `features/settings/`; `src/components/` dipecah menjadi `ui/`, `layout/`, `feedback/` plus layar yang kembali ke fiturnya; `constants/theme.ts` menjadi `src/theme/`; provider lintas aplikasi berkumpul di `src/providers/`; `lib/` dipecah menurut tanggung jawab dokumen (fungsi murni → `utils/`, integrasi platform → `lib/`, konten fitur → fiturnya). Nama fitur yang ada (budget, daily, home, plan, report, transaction-entry, transactions, wallet) **dipertahankan apa adanya** — dokumen sumber menyatakan nama fiturnya hanya contoh, dan rename digabung dengan refactor struktur hanya menghasilkan diff tak terbaca.

Alternatif yang dipertimbangkan: mempertahankan `services/` untuk service lintas fitur (ditolak — nama "services" sendiri dicatat dokumen sumber sebagai folder yang "terlalu luas"; pemilik yang jelas lebih penting daripada simetri folder), dan penegakan aturan dependensi dengan ESLint boundary plugin sejak awal (ditunda — jadi ticket opsional di akhir; konvensi dulu agar perpindahan file tidak terhambat linter).

Konsekuensi: aturan arah dependensi berlaku sebagai konvensi — `app` boleh impor fitur dan provider; fitur boleh impor shared (`components`, `utils`, `db`); shared tidak boleh impor fitur; satu fitur tidak mengambil komponen internal fitur lain. Perpindahan dikerjakan sebagai ticket tracer-bullet berurutan (rapikan `app` + grup `(tabs)` → layar ke fitur → `db` → `data/` → split `components/` + `theme/` + `providers/` → lint boundaries opsional), masing-masing meninggalkan repo tetap hijau.
