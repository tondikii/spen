# Taste — Communication

- Communicates in Bahasa Indonesia (Indonesian), including product/UI terms and UI copy, in a casual aku/kamu register (not formal saya/Anda); the agent should respond in the same language and register unless asked otherwise. Confidence: 0.95
- When the user challenges an existing pattern with their own intuition ("apakah itu best practice? karena setau ku bisa tidak perlu dibedakan, kan?"), they want the honest technical verdict — including blunt admissions like "ini bukan best practice, ini workaround" — the evidence for why the workaround exists, and a concrete path to eliminate it, not a rationalization defending the status quo; take the user's intuition seriously and validate or correct it with evidence (recurring pattern: `.native` route pairing, `src/app` route nesting, `+html.tsx` necessity). Confidence: 0.75
- Completion claims for structural work must be grounded in observable end-state the user can check themselves: the user inspects the repo immediately after a "done" report and challenges mismatches tersely ("daily sama transaction-entry masih terpisah tuh, apanya yang dimerge?"); include the concrete final layout (folder listing, commit hash) so the claim is verifiable, rather than leaning on "suite green / status clean" alone. Confidence: 0.6
- Recommendations floated as open questions in passing (e.g., "Mau kubuatkan ticket untuk konsolidasi itu?") can get lost between turns — the user later admits not remembering them ("oh tadi kamu merekomendasikan untuk merge fitur Transaksi ya? aku ga engeh soalnya"), and even mid-execution after a blanket approval they will halt the work ("bentar, jadinya merge daily + transaction-entry disarankan tidak? kalo tidak gausah") to demand the verdict; when resuming or asking for a go-ahead, recap the outstanding recommendations in one compact list so nothing is silently dropped, and state each recommendation as an explicit yes/no verdict with its strength (e.g., "daily → merge: kuat; transaction-entry → merge: ya; goal: tidak") rather than leaving it embedded in nuanced analysis — a blanket "terapkan semua rekomendasimu" only counts for items the user could see were actually recommended. Confidence: 0.7
